# Pro-ChE-ss Suite
#### Created by Jesus Isaiah B. Marfil, BSChE @ BUCENG

The Pro-ChE-ss Suite is a compilation of chemical engineering-related tools, calculators, and data that can be used by any aspiring Chemical Engineering students on their studies.

**Disclaimer:** All tools and programs are created by myself based on what I have learned so far. As time passes during my Chem Eng journey, this suite will also be updated in a rolling release.

Tools used: Python

Set Up (for now): 
- 
Install all files and folders, run logic.py on command prompt/terminal.

Status: Version 1
- 
- Currently runs on CLI
- Contains the following:
    - Molar Mass Parser
    - Stoichiometry Calculator
    - Titration Calculator
    - Mass Balance Calculator
- All run on Python


For further details so far, look up the documentation folder.
